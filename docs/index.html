CALC

La calculatrice qui calcule pendant que tu tapes. Elle tourne dans le terminal de ton téléphone Android (Termux) : calcul scientifique, outils de boutique en FCFA, mesure de terrain, graphiques, PIN et sauvegarde chiffrée.

▸ Installer en une ligne

pkg install -y git && git clone https://github.com/daboujohan-hub/calc-live && cd calc-live && bash install.sh

Colle la commande dans Termux (à installer depuis F-Droid ou GitHub), puis tape calc-live pour lancer l’outil. Testé sur Termux (Android).

▸ Comment ça marche

  1. Tu tapes. À chaque touche, l’expression est analysée et calculée aussitôt.
  2. Le résultat s’affiche en direct, en gros chiffres. Un petit coin en bas montre ce que la machine fait : jetons, arbre d’opérations, prêt ou incomplet.
  3. Entrée valide : le calcul entre dans ton historique.
  4. Tes données restent sur ton téléphone, dans des fichiers cachés de ton dossier personnel. Le PIN est protégé par PBKDF2 et les sauvegardes sont chiffrées en AES-256 avec OpenSSL.
